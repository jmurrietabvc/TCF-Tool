# Registro de reportes — TCF Canada EE, octubre de 2026

Este registro alimenta `ecrivance-october-2026.js`. Mantiene separados los
relatos de primera mano, las corroboraciones independientes y los rumores o
reposts. No cambies los temas históricos para añadir un reporte nuevo.

## Regla de publicación

1. Añadir solo un relato de primera mano o un reporte corroborado de forma
   independiente. Un post que solo repite otro reporte se conserva como
   referencia, pero no crea una nueva ficha.
2. Usar una clave estable: `tcf-ca-ee-AAAA-MM-DD-sede-normalizada`. Antes de
   añadirla, comprobar si ya existe el mismo `id`, fecha, sede y las tres tareas.
3. Conservar fecha, sede, tipo de fuente, enlace o nombre del hilo y nivel de
   confianza. Si los documentos de Tâche 3 no se publicaron, no inventarlos.
4. `firsthand` = el candidato dice haber realizado ese examen; `corroborated` =
   al menos dos fuentes independientes; `rumor` o `repost` = no publicar hasta
   verificarlo.
5. Revisar el diff completo y `git diff --check` antes de publicar.
