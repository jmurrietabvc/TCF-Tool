# Registre de reportes — TCF Canada EE, septiembre de 2026

Este registro alimenta `ecrivance-september-2026.js`. Mantiene separados los
relatos de primera mano, las corroboraciones independientes y los rumores o
reposts. No cambies los temas históricos para añadir un reporte nuevo.

## Regla de publicación

1. Añadir solo un relato de primera mano o un reporte corroborado de forma
   independiente. Un post que solo repite otro reporte se guarda como referencia,
   pero no crea una nueva ficha.
2. Usar una clave estable: `tcf-ca-ee-AAAA-MM-DD-sede-normalizada`. Antes de
   añadirla, comprobar si ya existe el mismo `id`, fecha, sede y las tres tareas.
3. Conservar exactamente: fecha de examen, sede, tipo de fuente, enlace o nombre
   del hilo, y nivel de confianza. Si no están disponibles los dos documentos de
   Tâche 3, nunca inventarlos: marcarlo en la ficha.
4. `firsthand` = el candidato dice haber realizado ese examen; `corroborated` =
   al menos dos fuentes independientes; `rumor` o `repost` = no publicar en la
   biblioteca hasta verificarlo.
5. Revisar `git diff --check` y el diff completo antes de publicar. El cambio
   debe limitarse a la nueva entrada y, si aplica, a este registro.
